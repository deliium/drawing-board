# Practice stroke-order player blank / order not shown after fluid canvas

**Date:** 2026-09-10 23:21
**Files:** web/src/components/practice/StrokeOrderPlayer.vue, web/src/i18n/locales/en.ts, web/src/i18n/locales/ja.ts, web/tests/helpers/stubCanvasContext.ts, web/tests/unit/stroke-order-reduced-motion.spec.ts
**Severity:** medium

## Problem

Guided practice `animate` stage (and “Show order again”) did not reliably show hiragana stroke order: blank or order-unclear canvas while Skip/Continue still appeared.

## Root Cause

Prompt 14 fluid-canvas cutover added `ResizeObserver` re-paint to `PracticeStageCanvas` but left `StrokeOrderPlayer` as a one-shot `onMounted` paint with no layout settle. Missing glyphs failed silently (`emit('done')` with empty canvas). Reduced motion jumped to the final glyph with no stroke index labels, so order was not readable.

## Solution

Align player lifecycle with practice canvas: `nextTick` before first paint, `ResizeObserver` re-paint of a snapshot frame (`paintUpTo` / `paintProgress`), 1-based stroke indices on the canvas, i18n empty-state hint, and `[FIX]` logging (glyph / contentVersion / size — never coordinates). Extended Vitest coverage for paint, missing glyph, indices, and resize repaint.

## Prevention

- When introducing shared fluid canvas sizing, update **all** practice canvases (trace, stroke-order, overlay) with the same settle + ResizeObserver pattern.
- Never allow empty trace lookup to finish without learner-visible copy and a `[FIX]` log.
- Prefer stroke index labels so order remains clear under `prefers-reduced-motion`.
