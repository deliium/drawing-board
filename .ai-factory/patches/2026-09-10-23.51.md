# Hiragana practice letter lines look broken / angular

**Date:** 2026-09-10 23:51
**Files:** web/src/canvas/smoothPath.ts, web/src/curriculum/hiragana5.ts, web/src/curriculum/hiragana5-traces.json, web/src/components/practice/StrokeOrderPlayer.vue, content/hiragana5/v1/traces.json, content/hiragana5/v1/manifest.json, content/hiragana5/v1/review.json, content/hiragana5/LICENSES.md, README.md, web/tests/**
**Severity:** medium

## Problem

Guided practice stroke-order animation and trace guides rendered hiragana as polygonal broken lines with sharp corners instead of smooth character strokes.

## Root Cause

UI traces were sparse control-point polylines (often 2–5 points) painted with straight `lineTo` segments. `lineJoin: 'round'` only softens joints slightly; it cannot invent curvature between distant vertices.

## Solution

- Densify `content/hiragana5/v1/traces.json` (and the frontend mirror) with smoother sampled paths while keeping stroke count/order.
- Add `pathSmoothPolyline` (midpoint quadratic curves) and arc-length `slicePolylineByFraction` for animation.
- Use them in `drawTraceTemplates` and `StrokeOrderPlayer`. Leave assessment `strokes.json` unchanged.
- Refresh `manifest.contentHash`; document denser UI traces vs assessment paths.

## Prevention

- Prefer denser UI traces (or curve rendering) for display; do not assume sparse assessment control points look acceptable on canvas.
- When changing pack geometry, refresh `contentHash` and keep frontend `hiragana5-traces.json` in sync with pack `traces.json`.
