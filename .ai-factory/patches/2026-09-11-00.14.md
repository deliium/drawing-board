# Practice hiragana lines look wrong / approximate

**Date:** 2026-09-11 00:14
**Files:** content/hiragana5/v1/traces.json, content/hiragana5/v1/strokes.json, content/hiragana5/v1/manifest.json, content/hiragana5/v1/review.json, content/hiragana5/LICENSES.md, web/src/curriculum/hiragana5-traces.json, internal/recognize/testdata/hiragana5/**, README.md
**Severity:** medium

## Problem

Guided practice stroke-order animation and trace guides for あいうえお did not resemble textbook kana: some strokes looked directionally off (especially お’s right mark as an open hook), and overall silhouettes were only rough polygons.

## Root Cause

UI traces (and matching assessment control paths) were hand-authored low-fidelity approximations. A prior densify/smooth pass improved corner joining but kept the same approximate control geometry, so learners still saw wrong-looking forms.

## Solution

- Reshape `content/hiragana5/v1/traces.json` (and the frontend mirror) to denser textbook-like polylines: closed お right loop, fuller あ/う curves, clearer い hooks and え elbows — same stroke counts/order.
- Align sparse `strokes.json` + gold/incorrect recognize fixtures to the new shapes; refresh `manifest.contentHash`.
- Leave canvas smoothing helpers unchanged; this fix is content geometry.

## Prevention

- When judging trace quality, compare silhouettes to font/textbook forms — densifying alone does not fix wrong topology.
- Keep UI traces and assessment stroke counts/order in lockstep; update gold + incorrect fixtures and `contentHash` together.
