# README License still claimed CC0 for KanjiVG stroke/trace geometry

**Date:** 2026-09-11 00:26
**Files:** README.md, internal/docguard/readme_honesty_test.go
**Severity:** medium

## Problem

After replacing hiragana5 stroke/trace geometry with KanjiVG-derived paths (CC BY-SA 3.0) and updating `content/hiragana5/LICENSES.md`, the README License section still stated that curriculum stroke/trace data were under CC0.

## Root Cause

Pack-local licensing was updated with the geometry change, but the repository-level License blurb was only partially updated (traces table row mentioned KanjiVG; the License section was left on the old CC0 wording).

## Solution

Rewrite the README License paragraph so pedagogy glosses stay CC0 and stroke/trace geometry (pack files + SPA mirror) are attributed as KanjiVG CC BY-SA 3.0 with a pointer to `content/hiragana5/LICENSES.md`.

Add `TestREADMEStrokeTraceLicenseMatchesPack` in `internal/docguard` so README cannot re-claim CC0 for stroke/trace geometry while the pack marks those files CC BY-SA.

## Prevention

- When third-party licensed assets enter `content/hiragana5/vN`, update `LICENSES.md` and the README License section in the same change.
- Keep `TestREADMEStrokeTraceLicenseMatchesPack` green (`go test ./internal/docguard`).
