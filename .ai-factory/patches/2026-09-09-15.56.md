## Problem

`/aif-verify` on Prompt 12 flagged two non-blocking gaps: README omitted named `ε_bounds` / `N_resample`, and the proportions incorrect fixture asserted `relative_placement` instead of `proportions`.

## Root Cause

1. Docs listed `L_short` / weights / `T_pass` but not every D2/D4 constant called out by the plan.
2. Pure length-ratio skew rarely fails `T_pass` (proportions weight is only 0.10). Distortions strong enough to fail also collapse placement, so coaching priority emitted `relative_placement` first.

## Solution

- Document `ε_bounds`, `N_resample`, and the full engineering-criteria constant set in README.
- Replace the proportions fixture with a stroke-2 spiral that fails overall and includes `proportions` in top-2 feedback; log `[FIX]` criterion breakdown in the fixture test.
- Clarify eval wording: expected correction code in top-2 (not only rank-1).

## Prevention

- When documenting assessment tolerances, mirror every named constant in `tolerances.go` into README’s engineering section.
- For low-weight criteria fixtures, design ink that fails overall while keeping higher-priority criteria above the soft threshold when possible; otherwise assert the code in top-2 and record the tradeoff in fixture `notes`.
